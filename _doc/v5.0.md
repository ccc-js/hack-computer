# v5.0 «合成到 LUT 及 FPGA 佈局展示»（Synthesis → PnR → STA） — 2026-10-25

## 目標
- 在 HDL 模擬器加入「合成 LUT」按鈕：把目前的晶片做 Flatten + LUT4 科技映射，
  印出 LUT 列表與真值表；再以 8×8（自適應）CLB 格子陣列做 FPGA 佈局展示，
  支援模擬退火（Simulated Annealing）佈局動畫、通道走線繞線與紅色 Critical Path／F_max 時序分析。

## Phase 1：科技映射（Techmap）
- 新增 `lib/hdl/synthesis.js`：`MicroSyn` 三段式合成
  1. Flatten：ElabChip 階層展平成位元級 NAND＋DFF 網表（含多重輸出連線 `out=t, out=out`、
     slice 綁定 `out[0..7]=outLow` 的 per-bit 別名統一，杜絕孤兒 net）。
  2. Optimize：常數傳遞、雙重否定、無用邏輯清除（alias/getRoot）。
  3. Techmap：NAND 邏輯錐（logic cone）貪婪覆蓋打包成 4-LUT，計算 16-bit init 真值表；
     貪婪擴張被拒而卡住的 leaf 會反覆升級為新 Root 補映射，保證無斷鏈／無孤兒驅動。
- DFF/ARegister/DRegister：時計單元拆 MUX+DFF；純組合輸出由 DFF 直接驅動時不產生假 LUT。

## Phase 2–4：FPGA 畫布、退火佈局、繞線與 STA
- 新增 `lib/hdl/pnr.js`：`MicroPnR`
  1. 虛擬 FPGA 島嶼架構：CLB 格子陣列（自適應尺寸，面積利用率約 0.6，最小 4×4）＋
     周邊 I/O Pad。
  2. 模擬退火佈局器：隨機交換兩格、HPWL（半周長線長）成本、溫度 100→0.05（×0.94 冷卻）；
     支援 `options.onSample` 每溫度層取樣，供前端播放退火動畫。
  3. 曼哈頓迷宮走線：net 由 driver 經水平→垂直通道畫到 sink（CLB 或 Pad）。
  4. 靜態時序分析：前向 arrival（LUT 1.2 ns＋每格線距 0.25 ns），回溯 Critical Path，
     輸出 F_max = 1000/T。

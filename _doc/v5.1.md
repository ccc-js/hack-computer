# v5.1 «ASIC 標準單元流程»（Synthesis → PnR → STA 的 ASIC 版） — 2026-10-25

## 目標
- 把 FPGA 與 ASIC 兩套 syn+pnr 分開：FPGA 是 v5.0 的 `lib/fpga/synthesis.js`＋`lib/fpga/pnr.js`；
  ASIC 新增 `lib/asic/`（micro-yosys-asic＋micro-innovus），共用前端的 Flatten/Optimize
  （MicroSyn），只換「科技映射 + 佈局 + 時序」這三段成標準單元流程。
- 前端「合成 LUT」浮層加「ASIC 視圖」切換：同一顆晶片可切 FPGA（LUT4/CLB 格子）與
  ASIC（標準單元 row-based）兩種視圖。

## Phase 1：標準單元合成（lib/asic/synth.js）
- `STDCELL` 精簡庫：INV（0.08 ns／1 µm²）、NAND2（0.12／2）、MUX2（0.20／4）、
  AOI21（0.16／3.2）、DFF（clk-q 0.30／setup 0.15／hold 0.05／8 µm²）。
- `AsicSyn.map(opt, chipName)`：吃 MicroSyn 的 `optimizeGates` 位元級 NAND/DFF 網表，
  圖樣重寫（pattern rewriting）出標準單元：
  1. **MUX2 圖樣**：d = (a&l)|(b&!l) 的通用形式——d=NAND(u,v)，u/v 各經一段
     「單扇出 INV 鏈」（0 級以上）落至 NAND 閘 r1=NAND(x1,s1)、r2=NAND(x2,s2)，
     且 (s1,s2) 互補（其一為另一的 INV 閘，net 可為 gate 或 PI）。併成
     MUX2(in=[s1,x1,x2])，吃掉本體＋兩條鏈＋r1/r2；失去用途的 INV 由 cleanup 死碼清除。
  2. **AOI21 圖樣**：d=NAND(n1,n2)、n1=NAND(a,b)、n2=INV(c)，單扇出併成
     AOI21(a,b,c) 接 INV → d（Or/Or(a,b) 常被吃，比 MUX 少 0.04 ns）。
  3. 基底：單輸入 NAND(x,x) → INV、雙輸入 → NAND2；DFF 直接映為 DFF cell。
- 兩階段決策：先全體試 MUX2（鏈較深、收益大；AOI 先搶走鏈節點會讓 MUX 失配），
  再對剩餘 gate 補試 AOI21；feeders 不可重複併用。
- 扇出統計用「同一 gate 內去重」：NAND(x,x) 的雙引用不算多扇出，否則 INV 鏈永遠失配。
- `evalCells(cells, env)`：純組合 cell 網表求值 helper（多趟直到不動點，O(n²) 但穩）。
- 效果：ALU 479 閘 → 594 cells（NAND2×127、INV×295、AOI21×77、MUX2×95），
  面積比 AMD LUT4 映射更能凸顯 Mux/BOr/Not 的重複結構。

## Phase 2：row-based 佈局＋STA（lib/asic/pnr.js）
- `AsicPnR.place`：以拓撲 level 成列（DFF 輸出重置 level），列高固定 2.2 µm、
  cell 佔寬 ∝ STDCELL 面積；統計 totalWireUm（Σ driver↔sink 曼哈頓距離，僅供報表）。
- `analyzeTiming`：兩平行 walk(max/min)
  - delay 模型：cell delay ＋ 0.02 ns/sink（fanout 負載）＋ 0.01 ns/µm × 幾何距離；
  - setup：T ≥ max(DFF: clkq + 組合路徑 + setup) → Fmax = 1000/T；
    純組合（無 DFF，如 ALU）改以 PI→PO 最長路徑當 critical path；
  - hold：min(DFF: clkq + 最短組合) − hold → hold slack（無 DFF 為 null）；
  - 回溯 critical path（每步選 arrival 最大的輸入來源 cell）。
- `asicPlaceAndRoute(netlist)` 入口，回傳 `{ placement, timing, stats }`。

## Phase 3：前端 ASIC 視圖（dist/hdl.js v23）
- `runSyn` 在 FPGA 流程旁加算 ASIC 流程（`window.HackAsic`），失敗不影響 FPGA 視圖；
- 「ASIC 視圖」鈕切換：canvas 畫 row-based cell（寬 ∝ 面積、欄位 type 塗色、
  critical path cell 紅框、row 標籤），側欄改 cell 清單＋標準單元細節
  （延遲/面積/setup/clk-q），stats 列改 ASIC 行（cells/面積 µm²/列/線長/Fmax/hold slack）；
- 合成報告加 ASIC 段落（各類 cell 統計、CELLS 清單、佈局與 STA 摘要）。

## 測試（test/test_asic.js，6 項全綠）
- And：NAND2+INV＝3 µm²、全真值表；Mux：偵測出 MUX2 圖樣＋8 組真值表；
- Bit：DFF×1＋MUX 前段被 MUX2 吃掉；
- ALU：48 組隨機向量 cell 網表 vs 位元級 NAND 參考逐 net 等效、
  MUX2 ≥ 8 顆、面積 > 100 µm²；
- PnR：ALU rows/線長/Fmax 正數、Bit 的 hold slack 分析。

## 已知取捨
- 佈局為啟發式（level 分列），未做退火（row-based 標準持續七）；
- delay 模型純經驗（無 precise load capacitance / transition）；
- cell 內部結構（AOI21 的 pull-down 網路）不做 device-level 分析。

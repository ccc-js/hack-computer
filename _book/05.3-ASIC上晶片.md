# 5.3 ASIC 上晶片：1348 標準單元與 34.8 MHz

## 從同一張網表出發

ASIC 後端與 FPGA 共用前端（2,224 顆化簡後 NAND+DFF），差別在映射與佈局：

```js
// node 直跑：AsicSyn().map(opt, 'CPU') → asicPlaceAndRoute()
// cells: 1348
// cellTypeCounts: { INV: 640, NAND2: 309, MUX2: 158, DFF: 48, AOI21: 193 }
// areaUm2: 2891.6
// rowCount: 139, maxRowWidthUm: 172.8
// totalWireUm: 91708.5
// timing: Fmax 34.8 MHz（criticalPathNs 28.75）
```

## 單元組成：peephole 重寫的成績單

2,224 顆 NAND 變成 1,300 顆組合單元＋48 顆 DFF：

| 單元 | 數量 | 佔比 | 面積 µm² | 來源 |
|---|---|---|---|---|
| INV | 640 | 49% | 640.0 | NAND(x,x) 自配對 → 面積減半 |
| NAND2 | 309 | 24% | 618.0 | 基底直接映射 |
| AOI21 | 193 | 15% | 617.6 | 圖樣 `(a&b)\|c` 吃掉 3 顆 NAND |
| MUX2 | 158 | 12% | 632.0 | 圖樣 `(a&l)\|(b&!l)` 吃掉 5+ 顆 |
| DFF | 48 | 4% | 384.0 | 時序元件直接保留 |
| **合計** | **1,348** | 100% | **2,891.6** | |

兩個圖樣合計吃掉 351 顆原始 NAND（193×3−1、158×5−1 的量級），
並把面積從純 NAND2 版的約 3,800 µm² 壓到 2,891.6 µm²——
**圖樣映射的價值就是面積**（2.4 節）。

## 139 列的晶面

拓撲深度成列（3.4 節）：48 顆 DFF 各自開啟新 stage，整個 CPU 排成
**139 列**、最寬列 172.8 µm。用 2.2 µm 列高估算：

$$\text{晶面高} \approx 139 \times 2.2 = 305.8\;\text{µm}，\quad
\text{面積} \approx 305.8 \times 172.8 \approx 52{,}842\;\text{µm}^2$$

（含列間通道與空白；cell 本體面積 2,891.6 µm² 只佔約 5.5%——
「合法即止」的佈局非常稀疏，這正是真實工具要做 legalization 與擁擠優化的空間。）

## 時序：28.75 ns 的帳單

| 項目 | 貢獻 |
|---|---|
| DFF clk→q | 0.30 ns（一次） |
| 組合 cell 串聯（數百顆，0.08–0.20 ns/顆） | 主體 |
| 線延遲 0.01 ns/µm × 累積距離 | 顯著（稀疏佈局的代價） |
| fanout 負載 0.02 ns × 扇出 | 小額多筆 |
| **總計** | **28.75 ns → 34.8 MHz** |

對照 FPGA 的 22.0 MHz：ASIC 版快 1.6 倍——但別忘了 4.3 節的警告，
這 1.6 倍主要是**模型定價差異**（LUT 1.2 ns vs cell 0.08–0.20 ns），
不是物理事實。兩個數字共同的定性結論是：
**Hack CPU 的單週期資料通路天然是長路，任何工藝下都不到高頻**。

## FPGA vs ASIC 總對照

| | FPGA | ASIC |
|---|---|---|
| cells | 392（344 LUT+48 DFF） | 1,348 |
| 面積 | 26×26 格（676 槽，58% 用） | 2,891.6 µm²（cell 本體） |
| 線長 | 約 4,100 格（SA 隨機） | 約 91,700 µm |
| Fmax | 22.0 MHz | 34.8 MHz |
| 佈局方法 | SA 退火 | 拓撲成列 |
| 檢查 | setup | setup＋hold |

> **讀法**：FPGA 的「面積」是架構槽位、ASIC 的面積是物理 µm²，
> 兩者不可直接比；可比的是**方法論**——同一張網表，
> 兩套工具鏈各自走完「映射→佈局→繞線→STA」，產出同構的報告。
> 這就是 EDA 作為一門學科的統一性。

## 在 hdl.html 裡看 ASIC 視圖

同一顆 CPU、同一個「合成 LUT」按鈕，把右上角的視圖切到 ASIC：

- `A④`：抽象視圖，土黃色 cell 按 level 成列；
- `A⑤/A⑥/A⑦`：row 佈局實體圖、線長、時序報告。

點任一 cell 可見其單元類型、面積、輸入 net——與本章表格逐項對得上。
